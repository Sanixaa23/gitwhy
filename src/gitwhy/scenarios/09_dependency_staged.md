## What to do

If you have not committed yet, unstage it and write the rule:

    git rm -r --cached {{first_dependency}}
    echo "{{first_dependency}}/" >> .gitignore
    git add .gitignore

Then check what is left staged:

    git diff --cached --name-only

> WARNING: `git rm -r --cached` does not delete files from disk, it only stops git
> tracking them — but written without `--cached` the same command deletes them from disk
> PERMANENTLY. If you already committed and pushed this directory, the files stay in
> history; shrinking the repository would mean rewriting it.
